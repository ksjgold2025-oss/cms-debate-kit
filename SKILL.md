# CMS Debate Kit

Turn a supplied book excerpt into a classroom-ready debate kit while keeping every claim traceable to the excerpt.

## Source boundary

- Treat the supplied excerpt as the only admissible evidence source unless the user explicitly defines another source set.
- Never present information absent from the excerpt as evidence, even if it is generally known or appears plausible.
- When the excerpt does not support a requested claim, write exactly `발췌문에서 확인 불가` instead of guessing, filling gaps, or importing outside knowledge.
- Distinguish interpretation from quotation. An interpretation must still be supported by identifiable excerpt passages.

## Quotation rules

- Copy quoted text verbatim. Do not correct, summarize, modernize, or silently omit wording inside a quotation.
- Attach the excerpt's paragraph number to every quotation.
- If paragraph numbers are missing, do not invent them. Ask the user to supply numbered text or create a numbered working copy while preserving the original, then cite the working-copy paragraph numbers clearly.
- During final verification, compare every quotation character-for-character with the source and confirm its paragraph number.

## Workflow

1. Inspect the excerpt, debate rules, and any provided templates. Identify paragraph numbering, missing material, and output requirements before drafting.
2. Derive debatable motions from tensions, choices, values, or conflicts that the excerpt actually supports. Reject motions that require outside facts to argue meaningfully.
3. Build evidence cards for each side. Each card should identify the claim, verbatim quotation, paragraph number, explanation of relevance, and any limitation. Mark unsupported items `발췌문에서 확인 불가`.
4. Produce the requested student worksheet and assessment rubric. Align their prompts and criteria with the motions, evidence cards, debate rules, and intended classroom activity.
5. Run citation verification across all deliverables. Check quotation fidelity, paragraph numbers, source support, cross-document consistency, and unsupported claims before reporting completion.

Adapt the exact document structure and number of items to the user's materials rather than imposing a fixed template.

## File safety and output location

- Preserve all original excerpts, debate rules, and templates. Do not edit, rename, move, overwrite, or delete them without separate explicit approval.
- Create working copies only when needed and label them clearly as derived files.
- Save every newly created document, code file, or report in the current book or project folder's `결과물` directory.
- Before writing files, show the user the planned operations, exact target files, expected result, and absolute save paths; wait for explicit approval.
- Limit changes to the approved file list and scope. Request fresh approval for additional changes.

## Completion report

Report the deliverables created, the number of files changed or added, their final absolute paths, and the citation-verification result. Explicitly list any items marked `발췌문에서 확인 불가`.
